# 컴퓨터비전 시험 공부

## 코드 주석으로 서술형·출력 문제 공부하기

관련 예제 27개는 실행 코드 전에 `[선행 이론]`을 넣었습니다. **정의·배경 → 필요한 조건과 원리 → 특성 사이의 절충·한계 → 아래 코드와의 연결** 순서로 읽으면 됩니다. PPT의 관련 쪽수를 표시했고, 현재 코드에서 구현하지 않는 내용은 이론으로 구분했습니다.

첨부한 ‘지역 특징의 조건’은 `ch5_1.py`와 `ch5_2.py` 맨 앞에 정리했습니다. 반복성·분별력·지역성·정확성·적당한 양·계산 효율을 각각 예와 함께 설명하고, 실시간/오프라인 작업의 선택과 조건 사이의 길항 관계도 넣었습니다. 다른 단원도 같은 방식으로 배경 이론을 보강했습니다.

관련 코드에서 `[서술형]`을 검색하면 **특징 → 장점 → 단점 → 활용 → 한 문장 답안** 순서로 읽을 수 있습니다. 이어지는 `[계산·코드 연결]`에는 수식·인자·배열 형식을 정리했습니다. `출력`을 검색하면 기존 `print`의 확인값과 조건을 찾을 수 있습니다.

히스토그램·GLCM·LBP/LTP는 `ch3_6.py`, 모멘트·Hu·모양 기술자는 `ch4_8.py`, Moravec·Harris·NMS·Hessian 비교는 `ch5_1.py`에 모았습니다. 현재 구현이 없는 이론은 **미구현/관련 이론**으로 구분했습니다. 기존 실행문과 출력값 주석은 유지했습니다.

제공된 PPT 6개를 아래 3권으로 정리했습니다. 관련 소스코드에는 한 줄씩이 아닌 실행 단계별 묶음 주석을 달았습니다. 문서에는 수식·강의 그림·계산 예시·코드 연결표와 복습 문제/답이 있습니다.
