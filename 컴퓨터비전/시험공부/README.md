[개념 빠른찾기](개념_빠른찾기.md)에서 각 방법을 **정의 → 원리 → 장점·단점 → 활용 → 시험 답안** 순서로 볼 수 있습니다. 관련 코드 주석은 **정의·장점·단점** 위주로 줄였습니다. 핵심 수식과 함수 사용법·출력값 설명은 코드 옆에 남겼고, 자세한 설명은 개념 빠른찾기와 기존 Word 정리에서 볼 수 있습니다.

## PPT 전체 확인

제공한 **PPT 8개·296슬라이드**를 확인하고, 빠진 함수 사용법·선택 인자·주석 예제를 보충했습니다. [PPT 전체 확인표](PPT_전체_확인표.md)에서 모든 슬라이드의 관련 코드와 구현/이론 구분을 볼 수 있습니다. 새 예제는 설명 주석이며 기존 실행문은 유지했습니다.

## 코드 주석으로 서술형·출력 문제 공부하기

관련 예제는 실행 코드 전에 `[핵심 이론]`을 넣었습니다. 먼저 파일 맨 위의 짧은 **개념 요약**을 읽고, **핵심 이론·함수 참고**와 코드 옆 설명을 보면 됩니다. PPT의 관련 쪽수를 표시했고, 현재 코드에서 구현하지 않는 내용은 이론으로 구분했습니다.

첨부한 ‘지역 특징의 조건’은 `ch5_1_해리스직접.py`와 `ch5_2_해리스함수.py` 맨 앞에 정리했습니다. 반복성·분별력·지역성·정확성·적당한 양·계산 효율을 각각 예와 함께 설명하고, 실시간/오프라인 작업의 선택과 조건 사이의 길항 관계도 넣었습니다. 다른 단원도 같은 방식으로 배경 이론을 보강했습니다.

관련 코드에서 `[개념]`을 검색하면 **정의 → 장점 → 단점**을 짧게 볼 수 있습니다. 활용과 시험 답안은 개념 빠른찾기에 정리되어 있습니다. 코드 옆에는 수식·인자·배열 형식을 정리했습니다. `출력`을 검색하면 기존 `print`의 확인값과 조건을 찾을 수 있습니다.

`[함수 사용]`은 **간단한 Python 호출 형식 + 주요 인자·반환값·입력 조건**을 두 줄 정도로 설명합니다. 코드와 주석 속 예제에 추가했으며 같은 파일의 반복 호출은 처음 한 번만 설명합니다. 영상 읽기·창 표시·키 대기·창 닫기는 `[함수 사용: 입출력·창]`으로 묶었습니다. 예를 들어 `merge`는 채널 배열 목록을 받으며 크기·dtype이 같아야 한다는 조건을 함께 적었습니다.

히스토그램·GLCM·LBP/LTP는 `ch3_6_히스토그램.py`, 모멘트·Hu·모양 기술자는 `ch4_8_모멘트.py`, Moravec·Harris·NMS·Hessian 비교는 `ch5_1_해리스직접.py`에 모았습니다. 현재 구현이 없는 이론은 **미구현/관련 이론**으로 구분했습니다. 기존 실행문과 출력값 주석은 유지했습니다.

제공된 PPT 7개를 아래 4권으로 정리했습니다. 관련 소스코드에는 한 줄씩이 아닌 실행 단계별 묶음 주석을 달았습니다. 문서에는 이론·강의 그림·비교·계산 예시·코드 연결표와 복습 문제/답이 있습니다.

## 1장 소개 정리

코드 주석 형식으로 한곳에서 읽으려면 [ch1_1_소개.py](../ch1_1_소개.py)를 여세요. 실행문 없이 정의·비교·특징·장단점·코드 연결·복습 문답을 `#%%` 단위로 모았습니다.
