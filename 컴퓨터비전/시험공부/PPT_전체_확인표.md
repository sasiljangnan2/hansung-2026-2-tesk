# PPT 전체 확인표

제공한 PPT **8개, 총 296슬라이드**의 본문·함수 선언 그림·예제·수식·과제를 확인한 코드 연결표입니다. 슬라이드 번호는 표지를 포함한 실제 순서입니다.

기존 이론 주석에 더해 이번에는 빠졌던 **함수 사용법과 선택 인자**를 보충했습니다. `[PPT 전체 확인 보충]`, `[PPT 함수 보충]`, `[PPT 인자 보충]`을 검색하세요. 기존 실행문·알고리즘·print는 유지했습니다.

`주석 예시`는 사용법을 읽는 참고 예제입니다. 새로 실행되는 구현이 아닙니다. 기존 코드에 없는 함수를 설명하려고 과제 코드에 실행문을 섞지는 않았습니다. 같은 함수가 여러 번 나오면 한 파일에서 처음 등장하는 곳을 중심으로 설명합니다.

표지·차례·설치·강의계획은 안내로, 수식만 나온 주제는 이론으로 연결했습니다. 그림을 전부 코드 주석에 복제한 것은 아닙니다. 수식·그림을 따로 공부하려면 기존 Word 정리를 함께 보세요.

## 이번에 보충한 부분

- 배열: `empty/full`, `argmin/argmax`, `reshape/transpose`, 정렬·자료형·예상 출력.
- 이진화: 다섯 방식의 비교 출력, 연결요소의 4/8이웃, `adaptiveThreshold` 사용 예.
- 필터·에지: 테두리 처리·깊이, `Laplacian/cartToPolar`, Canny의 미분 입력 형식.
- 외곽선·허프: 계층·검색/근사 모드, `HoughLines`와 `HoughLinesP`의 인자·반환 형식.
- 분할·특징: SLIC/RAG/Ncut/Snake/GrabCut의 선택 인자, Hu·polylines 참고 예제, LBP/LTP 계산 예.
- 그래프·시간: Matplotlib의 표시·눈금·곡선, `time.time`, 영상 캡처 메소드.

## 강의 표기에서 구분할 점

- Python의 반환값 형식과 C++의 출력 인자는 다릅니다. 선택 인자는 키워드로 적으면 혼동을 줄일 수 있습니다.
- `np.unit8` → `np.uint8`, `angleInDegree` → `angleInDegrees`.
- `bitwise_and`의 세 번째 위치 인자는 `dst`입니다. 마스크는 `mask=...`로 전달합니다.
- `HoughLinesP`의 다섯 번째 위치 인자는 `lines`입니다. 길이·간격은 `minLineLength=...`, `maxLineGap=...`로 적습니다.
- `cornerHarris`의 `blockSize`는 미분 곱 집계 이웃이며 가우시안 표준편차가 아닙니다.
- OpenCV의 YCrCb 채널 순서는 Y,Cr,Cb입니다. RGB/BGR의 표시 순서도 구분합니다.
- `findContours`의 입력 변경 설명은 버전 차이가 있습니다. 현재 OpenCV에서는 검색과 그리기의 변경 여부를 구분합니다.
- `HuMoments`와 `morphologyEx`는 PPT의 수식·연산 정의를 연결하는 참고 함수로 표시했습니다.
- 5장 차례의 SIFT·매칭·호모그래피는 제공된 34쪽 본문에서 전개되지 않습니다. 학습 범위에 새 구현을 덧붙이지 않았습니다.
